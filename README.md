Artifical intelligence driven Static Analysis(AISA) is a tool that automates static analysis of a file and uses AI model to correlate the collected data from the extraction to label if the file is a malware or if it is clear. It uses the extracted data to find the functionality of the malware, C2 domain and API calls(imports,exports) used by the file to conduct suspicious behaviour

1) Collection of data
Primary job of this program is to collect data from the sample provided, It first checks for Packing, if the file is packed then it does not proceed to collect strings, it unpacks the file using suitable packer and then continues to extract the strings, API calls, domains, download locations. The AI model is a trained model with entropy monitor to find readable strings and then we also find the API calls.
The data is collected broadly then is catogorised in catogaries such as C2 domain, website, file location, api calls.

2) Analysing of data
We use a ML trained model which analyses entropy, character ratio, url, path markers, api names, suspicious domains and then combines it with saved numeric weights to return a score between 0 and 1 to decide wether the file is suspicious or not. Then we run a second AI model to analyse all the data and to find its functionality and connect the collected evidence as evidence. if the pattern matches a certain malware type but some evidence is missing then the AI model attempts to collect that specific evidence from the file sample.
